Skult fonctionne en **détection gérée** : vous n'avez aucun paramétrage technique à faire. Lors de votre mise en route, l'équipe Skult calibre la détection sur votre activité, puis l'affine en continu avec vos retours. Cette page explique ce qui est configuré — et comment le faire évoluer.

## Ce qui est calibré pour votre organisation

| Paramètre | Ce qu'il détermine |
| --- | --- |
| **Périmètre géographique** | Les régions et départements surveillés pour vous. |
| **Types de collectivités** | Communes, EPCI, AOM, départements, régions — selon vos acheteurs réels. |
| **Seuils de population** | Par exemple « communes de plus de 20 000 habitants » ou au contraire « moins de 20 000 » selon votre marché. |
| **Contexte métier** | Votre offre, vos cas d'usage, vos mots-clés — le prompt d'analyse est rédigé sur mesure pour votre activité. |
| **Exclusions** | Les types de signaux à ne pas remonter (hors cible, trop faibles, concurrentiels…). |
| **Seuil de score et volume** | Le niveau de sélectivité : privilégier un flux resserré de signaux forts, ou une couverture plus large. |
| **Personas de contacts** | Les fonctions recherchées automatiquement pour chaque alerte (DGS, directeur technique, chargé de mission…). |

<Info>
  Chaque organisation a sa propre configuration d'analyse : deux clients Skult recevant le même document public n'auront **pas les mêmes alertes** — chacun voit le document à travers le prisme de son offre.
</Info>

## Faire évoluer votre ciblage

Votre ciblage n'est jamais figé. Trois cas fréquents :

<AccordionGroup>
  <Accordion title="Trop d'alertes, ou des alertes hors sujet">
    Demandez un resserrement : relèvement du seuil de score, exclusion d'un type de signal récurrent. Donnez 2–3 exemples d'alertes non pertinentes — c'est ce qui permet le réglage le plus précis.
  </Accordion>

  <Accordion title="Pas assez d'alertes">
    Demandez un élargissement : zones supplémentaires, seuil de population abaissé, nouveaux cas d'usage à détecter. L'équipe vérifie aussi que la couverture de vos zones est complète.
  </Accordion>

  <Accordion title="Votre offre évolue">
    Nouveau produit, nouveau segment, nouvelle région commerciale : signalez-le — le contexte métier de votre détection est mis à jour pour suivre votre stratégie.
  </Accordion>
</AccordionGroup>

Le canal : [Retours & ajustements](/guides/retours) dans l'application (catégories « Alertes à exclure », « Ajustement du ciblage »…) ou votre contact Skult directement. Les ajustements sont généralement en place **pour la détection de la semaine suivante**.

<Tip>
  Le réglage le plus efficace vient de vos statuts : marquer systématiquement les alertes non pertinentes en **Hors scope** donne à l'équipe Skult une base factuelle pour affiner votre détection.
</Tip>
